# magister-teknologi-informasi

Catatan dan artefak perkuliahan **Magister Teknologi Informasi**.

## Proyek aktif: Systematic Literature Review (SLR)

**Topik:** *Artificial Intelligence in DevOps Automation: A Systematic Literature Review of Applications, Benefits, Challenges, and Research Trends from 2016 to 2026*

Fokus adalah **AI for DevOps** — AI/ML/Deep Learning/AIOps/Generative AI/LLM/AI Agents
digunakan untuk meningkatkan atau mengotomasi aktivitas DevOps. MLOps/DevOps-for-AI bukan
fokus utama.

### Metodologi

- Kitchenham & Charters — guideline utama SLR Software Engineering
- PICOC — scope, RQ, dan search strategy
- PRISMA 2020 — reporting study selection
- IEEE — citation style
- Synthesis — descriptive quantitative + qualitative thematic
